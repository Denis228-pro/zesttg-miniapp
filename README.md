# ZeSt Energy Drinks - Telegram Mini App

Telegram Mini App для интернет-магазина энергетических напитков ZeSt в Нарьян-Маре.

## Обзор проекта

ZeSt - это современный, чистый и минималистичный интернет-магазин энергетических напитков со следующими функциями:

- Проверка возраста (18+)
- Каталог товаров с поиском и фильтрацией
- Программа лояльности ZeSt Club
- Список дополнительных услуг
- Корзина покупок с многошаговым оформлением заказа
- Профиль пользователя с управлением подпиской
- Панель администратора для управления товарами

## Брендирование и стиль

- Основной цвет: `#e33a1b` (оранжевый)
- Цвет фона: `#ffffff` (белый)
- Современный, чистый и минималистичный интерфейс

## Основные функции

### Проверка возраста
При первом запуске пользователи должны подтвердить, что им есть 18 лет, чтобы получить доступ к приложению.

### Каталог товаров
- Поиск в реальном времени на русском и английском языках
- Фильтрация по брендам, цене, вкусу и т.д.
- Отображение товаров с названием, ценой, изображением и описанием

### ZeSt Club
Подписная программа лояльности за 350 руб/месяц с преимуществами:
- Оптовые цены (скидка 20%)
- Бесплатная доставка по всем заказам

### Дополнительные услуги
- Доставка в Нарьян-Мар: 50 руб
- Доставка в рп. Искатели: 15 руб
- Доставка в точное время: +10 руб
- Пакет: 8 руб
- Подарочная упаковка: 35 руб
- Открытка: 50 руб

### Корзина и оформление заказа
Многошаговое оформление заказа в стиле авиакомпаний:
1. Просмотр корзины и редактирование
2. Выбор услуг
3. Сводка заказа и оплата

### Профиль пользователя
- Управление подпиской ZeSt Club
- Переключение отображения цен между членскими и розничными
- История заказов

## Следующие шаги

Для полной реализации необходимо разработать следующие компоненты:

1. Бэкенд с базой данных реального времени (рекомендуется Firebase Firestore)
2. Аутентификация с использованием initData Telegram WebApp
3. Полная функциональность панели администратора
4. Полный процесс оформления заказа с интеграцией платежей
5. Синхронизация обновлений товаров в реальном времени

## Запуск приложения

Для запуска приложение должно быть размещено и доступно через Telegram как Mini App. Во время разработки вы можете открыть `index.html` непосредственно в браузере, но некоторые функции Telegram работать не будут.
